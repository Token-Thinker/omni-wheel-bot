# Contributing

Thank you for your interest in contributing to this project! We welcome contributions of all kinds.

## Getting Started

1. Fork the repository and clone your fork.
2. Create a new feature branch: `git checkout -b feature/your-feature`
3. Make your changes in that branch.
4. Run `cargo fmt -- --check` and `cargo clippy --all -- -D warnings`.
5. Run tests with `cargo test --all`.
6. Commit your changes and push your branch to your fork.
7. Open a pull request against the `main` branch of the upstream repository.
